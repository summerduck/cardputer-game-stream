# Samsung remote + Bluetooth keyboard for Cardputer ADV

Infrared remote for Samsung TVs and the Samsung Freestyle projector (Samsung32 protocol, address `0x0707`, `A` switches to `0x0505`). **Tab** switches to a Bluetooth keyboard mode for typing text on the projector.

## Remote keys

| Key | Command |
|---|---|
| `;` `.` `,` `/` | arrows (repeat while held) |
| Enter | OK |
| `` ` `` / Backspace | back |
| `=` / `-` | volume |
| P / M / H | power / mute / home |
| S / N / E | source / menu / exit |
| A | switch IR address |

## Keyboard mode

Pair **Cardputer KB** on the projector under *Settings → Connection → External Device Manager → Input Device Manager → Bluetooth Device List*. Then type. Enter, Backspace, fn + `;` `.` `,` `/` for arrows, fn + `` ` `` for Esc. Latin letters only.
