# Pomodoro Timer for Cardputer ADV

A focus timer: 25 minutes of work, a 5-minute break, and a 15-minute break after every 4 rounds. You can change all of these.

- Big 7-segment countdown, coloured by phase: red for focus, green for a break, blue for a long break. Grey means paused.
- Dots show the rounds done before the next long break; "всего" counts all finished rounds.
- When a phase ends it plays a chime, rising after focus and falling after a break. The time blinks and counts how long you've gone over. The chime repeats once a minute, up to 3 times, until you press Enter.
- With **Автостарт** on, the next phase starts by itself.
- While the timer runs the screen dims after 20 s. The first key press only turns it back up.
- Settings, brightness and the total are kept in flash. No SD card needed.

## Keys

| Key | Timer | Settings |
|---|---|---|
| Space / Enter | start / pause; after the chime, next phase | |
| `;` `.` | +1 / −1 minute on the running phase | select row |
| `,` `/` | | less / more |
| N | skip to the next phase (a skipped focus round isn't counted) | |
| R | restart the phase | |
| T | settings | back |
| M | sound on / off | |
| B | brightness | |
| H | key help | |
